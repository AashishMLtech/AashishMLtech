## 🚀 Featured Projects

### 🤖 NL2SQL Assistant

> Natural Language → SQL assistant powered by **LLMs, RAG and PostgreSQL**

* 🧠 Converts natural language questions into SQL queries
* 🔎 Uses semantic search for schema/context retrieval
* 🗄️ PostgreSQL + **pgvector**
* ⚡ FastAPI backend with Streamlit interface
* 🔗 LangChain-based AI pipeline

---

### 💬 RAG Knowledge Chatbot

> AI chatbot capable of answering questions using retrieved external knowledge.

* 🔗 Retrieval-Augmented Generation
* 🧠 LLM + embeddings
* 🔎 FAISS vector search
* 🌐 Streamlit interface
* 📚 Context-aware responses

---

### 📊 Twitter Sentiment Analysis

> NLP-based sentiment and hate-speech analysis using machine learning.

* 🧹 Text preprocessing & tokenization
* 📐 TF-IDF feature extraction
* 🤖 SVM & Logistic Regression
* 📈 Achieved approximately **87% accuracy**

---

### 🌫️ AQI Prediction

> Machine Learning system for predicting Air Quality Index.

* 📊 Data preprocessing & feature engineering
* 🤖 KNN, SVM and LSTM models
* 📈 KNN achieved **84.89% accuracy**
* 🧠 Sequential prediction using LSTM
